# 基础知识

在进入正式题目之前，我想先把第二章的部分重要的基础知识写一遍，这一板块的主要目的是自己复习，所以读者可以跳过直接到题目解答。

lab默认条件：32位操作；使用补码表示有符号整数；右移采用算术右移。
## 无符号数与补码

几个相当重要的补码性质：
```C
-x=~x+1
x^x=0
x^0=x
```

运算符：

| 运算符  | 含义   | 例子                          |
| ---- | ---- | --------------------------- |
| `&`  | 按位与  | `0b1100 & 0b1010 = 0b1000`  |
| `\|` | 按位或  | `0b1100 \| 0b1010 = 0b1110` |
| `^`  | 按位异或 | `0b1100 ^ 0b1010 = 0b0110`  |
| `~`  | 按位取反 | `~0 = 0xffffffff`           |
| `<<` | 左移   | `1 << 4 = 16`               |
| `>>` | 右移   | `-8 >> 1 = -4`（算术右移）        |
| `!`  | 逻辑非  | `!0 = 1`，`!5 = 0`           |
| `+`  | 加法   | `~x + 1 = -x`               |

常用恒等式：

c

```
x ^ y = (x & ~y) | (~x & y)
x | y = ~(~x & ~y)
x & y = ~(~x | ~y)
```


## 左移和右移

**左移**：低位补 0。
```
0x00000001 << 31 = 0x80000000
```

**逻辑右移**：高位补 0。
```
0x80000000 >>> 1 = 0x40000000
```

**算术右移**：高位补符号位。
```
0x80000000 >> 1 = 0xC0000000
0x7fffffff >> 1 = 0x3fffffff
```

一个非常常用的技巧：
```c
int mask = x >> 31;
```

- 如果 `x < 0`，`mask = 0xffffffff`；
- 如果 `x >= 0`，`mask = 0`。

## **掩码**

相当有意思的就是这个掩码了。

因为datalab的整数部分不允许使用if, 那么就需要用位运算来实现if。
```c
int mask =0或-1;
return (y & mask) | (z& ~mask);
```
当mask=-1时，结果等于y；当mask=0时，结果等于z;

生成全0/全1掩码的常用方法：

```c
int mask =x>>31;   //根据x的符号位生成
int mask =!x + ~0;  //根据x是否为0生成，为0就是全0,不为零就为全1
```


## IEEE 754 单精度浮点数

在这个lab环境下，单精度浮点数共三位：
```
1 位符号位 | 8 位阶码 | 23 位尾数
```
```
31        30        23 22                    0
| 符号 sign | 阶码 exp |       尾数 frac        |
```

偏移量：127

三种情况：

**规格化数**
```
exp != 0 且 exp != 0xFF
E = exp - 127
尾数 = 1.frac
```

所以数值为：
```
(-1)^sign * 1.frac * 2^(exp - 127)
```

**非规格化数**
```
exp == 0
E = 1 - 127 = -126
尾数 = 0.frac
```

非规格化数没有隐含的 1，用来表示非常接近 0 的数。

**特殊值**
```
exp == 0xFF 且 frac == 0：正负无穷
exp == 0xFF 且 frac != 0：NaN
```

浮点数转整数时，核心步骤是：

1. 取出 `sign`、`exp`、`frac`；
2. 计算 `E = exp - 127`；
3. 给 `frac` 补上隐含的 1：`mag = frac | 0x800000`；
4. 根据 `E` 和 23 的关系左右移位；
5. 根据符号位取相反数。


```
最小非规格化数：2^-149
最小规格化数：2^-126
最大有限数：约 2^128
```

## 1. bitXor

这题要求只能用 `~` 和 `&` 实现异或。我的做法是：

```c
int bitXor(int x, int y) {
  return ~(~x&~y)&~(x&y);
}
```

本质上是：

```c
x ^ y = (x | y) & ~(x & y)
```

再用德摩根律把 `|` 换成 `~` 和 `&`。

## 3. isTmax

判断 `x` 是否为 `0x7fffffff`。

```c
int isTmax(int x) {
  return !((x+1)^(~x))&!!(x+1);
}
```

思路是：如果 `x` 是最大值，那么 `x+1` 和 `~x` 相等。后面再 `!!(x+1)` 是为了排除 `x = -1` 的情况，因为 `-1 + 1 = 0` 也会让 `(x+1) ^ (~x)` 等于 0。

## 4. allOddBits

判断所有奇数位是否为 1。

```c
int allOddBits(int x) {
  int mask=0xAA;       //A=1010 对应奇数位
  mask=mask|(mask<<8);
  mask=mask|(mask<<16);
  return !((x&mask)^mask);  //!((~x)&mask)也可以
}
```

这里我留了一个注释：`!((~x)&mask)` 也可以。两种写法本质一样，都是判断 `x` 是否包含所有 `0xAA...` 中的 1。

## 5. negate

```c
int negate(int x) {
  return ~x+1;
}
```

补码求相反数，`-x = ~x + 1`。

## 6. isAsciiDigit

判断 `0x30 <= x <= 0x39`。

```c
int isAsciiDigit(int x) {
  int a=x+~0x30+1;
  int b=x+~0x3a+1;
  return !(a>>31)&!!(b>>31);    //看符号位是否为1来判断是否是负数;
}
```

- `a = x - 0x30`，如果 `a >= 0`，说明 `x >= 0x30`；
- `b = x - 0x3a`，如果 `b < 0`，说明 `x < 0x3a`。

两个条件同时成立，就说明 `x` 是 ASCII 数字字符。

## 7. conditional

实现 `x ? y : z`。

```c
int conditional(int x, int y, int z) {
  int mask=!x+~0;    //不能用~(!x),因为当x==0时，mask=0xFFFFFFFE,无法完全遮掩y
  return (y&mask)|(z&(~mask));
}
```

这是我踩过的一个坑，注释里写得很清楚：

> 不能用 `~(!x)`，因为当 `x == 0` 时，`mask = 0xFFFFFFFE`，无法完全遮掩 `y`。

正确思路是让 mask 要么是全 0，要么是全 1：

- 如果 `x == 0`，`!x = 1`，`mask = 1 + (-1) = 0`，选择 `z`；
- 如果 `x != 0`，`!x = 0`，`mask = 0 + (-1) = 0xFFFFFFFF`，选择 `y`。

## 8. isLessOrEqual

判断 `x <= y`。

```c
int isLessOrEqual(int x, int y) {
   int sign_x=(x>>31)&0x1,sign_y=(y>>31)&0x1;
   int sign=sign_x^sign_y;
   int minus=x+~y+1;    //如果最后发现操作符数量不够，可以将这里改为x+~(y+1)+1
   int sign_minus=(minus>>31)&0x1;
   int isEqual=!minus;
   int res=(sign&sign_x)|(!sign&(sign_minus|isEqual));
  
  return res;
}
```

这里我的注释留下了一个优化思路：

> 如果最后发现操作符数量不够，可以将这里改为 `x+~(y+1)+1`。

核心思想是：

- 当 `x` 和 `y` 异号时，直接看 `sign_x`，负数一定更小；
- 当同号时，用 `x - y` 的符号判断，同时处理等于的情况。

## 9. logicalNeg

实现 `!` 运算符。

```c
int logicalNeg(int x) {
  //这道题可以认为就是找x==0的等价条件，而在逻辑或位运算中或以及按位或当且仅当两边都为0才输出0,因此联想到尝试用符号位构造，得到x|-x
  int res=((x|(~x+1))>>31)+1;   //当x！=0时，res=0=！x；当x==0时,res=0+1=1=!x

  return res;
}
```

我在这题留了很长一段注释，核心想法是：

> 这道题可以认为就是找 `x == 0` 的等价条件，而在逻辑或位运算中，或以及按位或当且仅当两边都为 0 才输出 0，因此联想到尝试用符号位构造，得到 `x | -x`。

当 `x != 0` 时，`x` 和 `-x` 至少有一个最高位是 1，所以 `x | -x` 的符号位为 1，右移后是 `0xFFFFFFFF`，加 1 变成 0；当 `x == 0` 时，`0 | 0 = 0`，右移后是 0，加 1 变成 1。

## 10. howManyBits

这题是整数题里最需要想清楚的一道。

```c
int howManyBits(int x) {
  int b16, b8, b4, b2, b1, b0;

  //这里容易陷入一个误区：默认补码一定是32位，但看到howManyBits(0)  = 1就能反应过来，这里的位数允许变化，问的是最少需要的位数
  //因此，对于正数，只需要找到最高位的1；对于负数，由于类似11101=101的补码性质：对于位数全为1的情况，只需要1位就能做到；
  //故而可以假设为0的最高位是在i位，因此就在howManyBits(~x)基础上+1(符号位)就可以了，等价于howManyBits(~x+1)
  //由于~等价于x^1,因此只需要用x的符号位来判断是否需要取反;
  x=(x>>31)^x;    //视x的情况取反

  //接下来就该寻找最高位的1了,使用二分法
  b16=(!!(x>>16))<<4;    //高16位如果有1，!!(x>>16)为1,b16为16
  x=x>>b16;
  b8=(!!(x>>8))<<3;
  x=x>>b8;
  b4=(!!(x>>4))<<2;
  x=x>>b4;
  b2=(!!(x>>2))<<1;
  x=x>>b2;
  b1=(!!(x>>1));
  x=x>>b1;
  b0=x;

  return b16+b8+b4+b2+b1+b0+1;
}
```

我在注释里记录了一个很重要的误区：

> 这里容易陷入一个误区：默认补码一定是 32 位，但看到 `howManyBits(0) = 1` 就能反应过来，这里的位数允许变化，问的是最少需要的位数。

对于负数，关键是利用补码的性质：

> 对于位数全为 1 的情况，只需要 1 位就能做到；所以可以假设为 0 的最高位是在 `i` 位，因此就在 `howManyBits(~x)` 基础上 `+1`（符号位）就可以了，等价于 `howManyBits(~x+1)`。

后面再用二分法找最高位的 1，这种位运算的二分也卡了我好久，虽然第一时间想到二分查找，但实践起来还是有点别扭的。


## 11. floatScale2

实现 `2.0 * f`。

```c
unsigned floatScale2(unsigned uf) {
  unsigned exp=(uf>>23)&0xFF,sign=(uf>>31)&0x1;
  if(exp==0xFF){return uf;}     //这里能用if-else还有点不习惯,笑
  else if(exp==0){
    return (uf<<1)|(sign<<31);
  }
  else{
    exp+=1;
  }
  if(exp==0xFF){
    return (sign<<31)|(exp<<23);
  }
  return (uf&0x807FFFFF)|(exp<<23);   //1 0000 0000 111 1111 1111 1111 1111 1111   这个作用是为了保留原来的符号位和尾数 
}
```

因为前面做整数题习惯了“不能用控制流”，到了浮点题突然放开了，反而不适应。


## 12. floatFloat2Int

实现 `(int) f`。

```c
int floatFloat2Int(unsigned uf) {
  int sign =(uf>>31)&1;
  int exp=(uf>>23)&0xFF;
  int frac=uf&0x7FFFFF;
  int E=0,mag=0;
  if(exp==0xff)return 0x80000000;
  if(exp==0)return 0;
  E=exp-127;
  if(E<0)return 0;
  if(E>=31)return 0x80000000;
  mag=frac|0x800000;
  if(E<23)mag=mag>>(23-E);
  else
    mag=mag<<(E-23);
  if(sign)return ~mag+1;
  else
      return mag;
}
```

这题没有留下太多注释，但思路很清晰：

1. 处理特殊值：NaN、无穷返回 `0x80000000`；
2. 非规格化数返回 0；
3. 计算真实指数 `E = exp - 127`；
4. 加上隐含的 1，得到尾数 `mag = frac | 0x800000`；
5. 根据 `E` 和 23 的关系移位；
6. 最后根据符号位取反加 1。

## 13. floatPower2

计算 `2.0^x`。

```c
unsigned floatPower2(int x) {
    if(x<-149)return 0;
    if(x<-126)return 1u<<(x+149);
    if(x<128)return (x+127)<<23;
  
    return 0x7F800000;
}
```

这题其实就是根据 `x` 的范围判断结果落在哪一类：

- `x < -149`：小于最小的非规格化数，返回 0；
- `-149 <= x < -126`：非规格化数，直接移尾数；
- `-126 <= x < 128`：规格化数，阶码是 `x + 127`；
- 否则返回正无穷。
